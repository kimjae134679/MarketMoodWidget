# MarketMoodWidget

삼성 갤럭시 홈 화면 위젯을 지원하는 **공포 & 탐욕 지수 / 시장 지표 Android 앱**입니다.

## 핵심 기능
- 레퍼런스와 흡사한 나스닥/코스피 공포·탐욕 화면
- 이전 지수: 지난 거래일 / 일주일 전 / 한 달 전 / 1년 전
- 최근 10주 주봉 추이
- 최신 거래일 기준 코스피/코스닥/나스닥 지수와 등락률
- 날짜를 직접 선택해 해당 거래일의 코스피/나스닥 등락률 조회
- 삼성 갤럭시 홈 화면 AppWidget 지원
- 위젯: 코스피/나스닥, 라이트/다크, 게이지/주봉 그래프 선택
- 사이드카·서킷브레이커: 정상 시 완전히 숨김, 발동 확인 시에만 코스피에 표시

## 권한
- `INTERNET`: 시장 데이터 조회
- `ACCESS_NETWORK_STATE`: 네트워크 상태 확인

연락처/사진/위치/알림 권한은 요청하지 않습니다.

## 갤럭시 위젯 추가
1. APK 설치 후 앱을 한 번 실행합니다.
2. 홈 화면 빈 공간을 길게 누릅니다.
3. `위젯`을 선택합니다.
4. `공포 & 탐욕 지수`를 찾습니다.
5. 홈 화면에 놓고 코스피/나스닥, 다크/라이트, 게이지/주봉 그래프를 선택합니다.
6. 삼성 One UI 홈에서 위젯 크기를 드래그해 조절할 수 있습니다.

## 데이터 안내
- 코스피/코스닥/나스닥 가격 데이터는 네트워크 조회 후 로컬 캐시에 저장됩니다.
- 공포·탐욕 점수는 공식 거래소 지수가 아니라 가격 흐름, RSI, 이동평균, 모멘텀을 조합한 자체 추정치입니다.
- 네트워크 실패 시 마지막 성공 캐시를 사용합니다.

## APK 빌드
GitHub Actions의 **Build Android APK** 워크플로가 `main`에 푸시될 때 자동으로 디버그 APK를 빌드하고 Artifact로 업로드합니다.
